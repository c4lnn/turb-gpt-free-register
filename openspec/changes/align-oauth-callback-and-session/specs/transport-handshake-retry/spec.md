# Spec Delta

## MODIFIED Requirements

### Requirement: 请求发出后的连接中断不重试
除显式要求跳过成功响应正文读取的情形外，请求体已发送到服务端后，因连接被关闭或重置导致的失败（不含超时），传输会话 MUST NOT 自动重试，直接向调用方抛出错误。

#### Scenario: 请求发出后对端无响应关闭
- **WHEN** 请求体已发出，对端未返回任何响应字节即关闭连接
- **THEN** 系统向调用方抛出连接错误，共发出 1 次请求

#### Scenario: 响应体不完整
- **WHEN** 默认请求中服务端返回的响应体在传输中途中断，长度小于声明的 Content-Length
- **THEN** 系统向调用方抛出连接错误，共发出 1 次请求

#### Scenario: 请求发出后对端无响应重置
- **WHEN** 请求体已发出，对端未返回任何响应字节即重置连接
- **THEN** 系统向调用方抛出连接错误，共发出 1 次请求

#### Scenario: 响应体传输中被重置
- **WHEN** 默认请求中服务端返回的响应体在传输中途中断，随后连接被重置
- **THEN** 系统向调用方抛出连接错误，共发出 1 次请求

## ADDED Requirements

### Requirement: 显式流式请求在成功状态码下跳过正文读取
当调用方显式启用流式跳过正文模式且收到小于 400 的 HTTP 响应状态码时，传输会话 SHALL 仅读取并记录状态码、最终地址、响应头及包含重定向过程在内的 Cookie，MUST NOT 读取响应正文，也不强制关闭底层可复用连接。

#### Scenario: 启用流式跳过读取 200 响应正文并保留 Cookie 与复用
- **WHEN** 调用方启用流式跳过模式发起请求，服务端经重定向或直接返回 HTTP 200、Set-Cookie 与持续下发的响应正文
- **THEN** 传输会话正常返回响应对象，响应状态码、响应头及 Cookie 均已记录到会话中
- **AND** 响应对象的正文内容为空，且不读取剩余响应流
- **AND** 若底层协议支持多路复用，不主动标记底层连接不可复用

#### Scenario: 启用流式跳过但响应头之前链路瞬断仍重试
- **WHEN** 启用流式跳过模式的请求在连接建立阶段或等待响应头期间发生链路瞬断
- **THEN** 传输会话仍按既有链路瞬断规则同一会话内重试

#### Scenario: 启用流式跳过但收到错误状态码时仍读取完整正文
- **WHEN** 调用方启用流式跳过模式，服务端返回 HTTP 400 及以上状态码
- **THEN** 传输会话仍完整读取错误响应正文与响应头供上层诊断
- **AND** 若该错误响应正文在传输中途中断，仍按既定规则映射为连接异常

#### Scenario: 流式参数之外的未知请求参数仍被拒绝
- **WHEN** 调用方传入除既有支持参数和流式跳过开关之外的未知关键字参数
- **THEN** 传输会话仍显式拒绝并抛出参数错误
