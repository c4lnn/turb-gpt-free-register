# Spec Delta

## Purpose

定义 WebUI 代理池配置的可编辑与保存行为，使用户能够通过多行文本维护代理条目，并将空列表明确保存为清空配置。

## ADDED Requirements

### Requirement: 代理池始终使用可编辑的多行文本字段
WebUI MUST 将 `PROXY_POOL` 显示为可编辑的多行文本字段，不得因当前值或草稿值为空或非空而切换为选择控件。

#### Scenario: 编辑已有代理池
- **WHEN** 用户打开包含一个或多个代理条目的配置
- **THEN** 用户可以在多行文本字段中编辑已有条目并继续输入其他条目

#### Scenario: 从空代理池添加条目
- **WHEN** 用户在空的代理池字段中输入第一条代理 URL
- **THEN** 字段仍为可编辑的多行文本字段，用户可以继续输入后续条目

### Requirement: 代理池文本按行保存并支持清空
WebUI MUST 将代理池文本中每个去除首尾空白后的非空行作为一个代理条目保存，并 MUST 允许用户保存空字段以清空代理池。

#### Scenario: 保存多个代理条目
- **WHEN** 用户保存包含多条代理 URL 和空行的代理池文本
- **THEN** 保存结果只包含非空代理行，重新加载后每个代理条目仍各占一行

#### Scenario: 清空代理池
- **WHEN** 用户清空代理池字段并保存配置
- **THEN** 保存后的代理池为空，重新加载后字段仍为空
