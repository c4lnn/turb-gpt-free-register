# Spec Delta

## Purpose

账号管理界面为用户呈现账号记录、筛选条件和账号操作。本能力约束该页面的内容层级，确保账号记录成为主要工作区域，并避免重复概览信息干扰操作。

## ADDED Requirements

### Requirement: 账号管理页不显示全局资源概览
当用户打开账号管理页面时，界面 MUST 保留页面主标题和自动刷新状态，但 MUST 不显示标题下方的页面说明或全局资源概览卡片。

#### Scenario: 打开账号管理页面
- **WHEN** 用户选择账号管理页面
- **THEN** 页面显示主标题和自动刷新状态，不显示标题说明及资源概览卡片

#### Scenario: 打开其他控制台页面
- **WHEN** 用户选择账号管理以外的控制台页面
- **THEN** 该页面原有的页面说明和全局资源概览行为保持不变

### Requirement: 账号内容区不重复页面标题
账号管理内容区 MUST 直接呈现已注册账号卡片，不得重复显示账号管理标题及其密码与令牌说明。

#### Scenario: 查看账号列表
- **WHEN** 用户进入账号管理页面
- **THEN** 主页面标题之后呈现已注册账号卡片及其现有筛选、批量操作和列表功能
